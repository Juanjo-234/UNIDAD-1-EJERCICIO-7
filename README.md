# UNIDAD-1-EJERCICIO-7
Resolución del ejercicio N°7 de  la unidad 1 programación 2.
Este programa gestiona el registro y control de lectura de un tomo de manga o cómic en una biblioteca personal.
El programa permite actualizar y consultar su estado a medida que el usuario lo lee.
Al fina mostrara un informe donde indica el titulo del manga, el volumen y el estado de lectura.
